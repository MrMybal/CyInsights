Quest embedded collection: `CyInsights.QuestGpuMetrics=1` enables available `XR_META_performance_metrics` readings during an active trace with its `counters` channel. The default poll rate is 10 Hz; `CyInsights.Start` includes the channel on Android even if the capture channel list is overridden. Collection needs no external monitoring application and restores initially disabled runtime metrics after the plugin stops its capture. Every metric carries native units and validity; invalid/nonfinite readings do not become zero GPU times. The runtime does not expose an execution-frame ID or original measurement interval, so observation game frames and CPU cycles are explicitly separate from GPU execution. The provider follows Unreal's OpenXR extension hooks; a different XR backend requires its own adapter.
