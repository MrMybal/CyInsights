# Commencer ici {#title}

CyInsights analyse sous Windows les timings CPU/GPU Unreal, compteurs, tâches, activités et données GPU complémentaires. CyInsightOVR fonctionne sur Quest : courbes système, compteurs optionnels de géométrie soumise, snapshots de tuiles et overlays de développement. Le plugin Unreal est un composant de capture distinct.

## Choisir un parcours {#choose-your-workflow}
1. Vous avez une trace ? Lire [Ouvrir les captures](doc:opening-traces), puis [Timeline](doc:timeline).
2. Enregistrer un jeu Unreal PC ou Quest ? Lire [Plugin Unreal](doc:unreal-plugin), [Profils](doc:profiles) et [Capture Quest](doc:quest-capture).
3. Utiliser le compagnon sans PC ? Lire [Installation CyInsightOVR](doc:quest-setup) et [Configuration du HUD](doc:quest-hud).
4. Chercher un ralentissement ? Lire [Frames](doc:frames), [Fonctions](doc:functions) et [Données GPU](doc:gpu-desktop).

## Utiliser ce manuel {#use-this-manual}
La recherche consulte les titres, le texte et les sources indexées. English / Français change la langue du lecteur indépendamment de l’application. Le sommaire regroupe CyInsights, CyInsightOVR, les guides communs, les références techniques et l’historique. Les liens ouvrent la bonne page ou section ; Retour/Suivant du navigateur conserve la navigation. La position de lecture est gardée pendant la session.

Les commandes d’image permettent le zoom, le déplacement et l’agrandissement dans la fenêtre. Échap réduit une image agrandie. Les commandes restent accessibles au clavier et au toucher. Plusieurs thèmes sont disponibles, dont un contraste élevé ; Nord est le thème initial.

L’application distribue le dossier **help/** complet. Windows ouvre son index.html par une URL locale ; CyInsightOVR ouvre le même export depuis les ressources de l’APK. Aucun compte, serveur, CDN ni téléchargement n’est nécessaire à la lecture. Les captures sont de vraies vues ; les schémas sont explicatifs, pas des mesures de votre trace.

L’anglais est la langue initiale et de repli. Les 24 chapitres utilisateur ont leur traduction française et des identifiants communs. Les archives techniques et les schémas API exacts restent dans leur langue d’origine, avec une mention explicite ; [État des traductions](doc:translation-report) indique les traductions restantes. Des références datées décrivent l’ancien fonctionnement ; les guides actuels priment.
