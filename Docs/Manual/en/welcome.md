# Start here {#title}

CyInsights analyzes recorded Unreal CPU/GPU timing, counters, tasks, activities and optional GPU evidence on Windows. CyInsightOVR runs on Quest: system curves, optional submitted-geometry counters, GPU tile snapshots and development overlays. The Unreal plugin is a separate capture component.

## Choose your workflow {#choose-your-workflow}
1. Already have a trace? Read [Open recordings](doc:opening-traces), then [Timeline](doc:timeline).
2. Record a PC or Quest Unreal game? Read [Unreal plugin](doc:unreal-plugin), [Capture profiles](doc:profiles) and [Quest capture](doc:quest-capture).
3. Use the companion without a PC? Start with [CyInsightOVR setup](doc:quest-setup) and [HUD configuration](doc:quest-hud).
4. Investigate a slowdown? Read [Frames](doc:frames), [Functions](doc:functions) and [GPU evidence](doc:gpu-desktop).

## Use this manual {#use-this-manual}
Search finds titles, text and indexed source. English / Français changes the reader language independently of the application. The sidebar groups CyInsights, CyInsightOVR, shared guides, technical references and history. Internal links open the relevant page or section; browser Back/Forward preserves navigation. Reading positions are retained during the reader session.

Use the image controls to zoom and pan screenshots, or enlarge them inside this window. Escape reduces an enlarged image. Controls are available on keyboard focus and touch devices. The theme selector offers dark, light and high-contrast themes; the initial theme is Nord.

The application ships the complete **help/** directory. Windows opens its index.html through a local file URL; CyInsightOVR opens the identical export from its APK assets. No account, server, CDN or download is required to read it. Screenshots are actual application views; diagrams are explanatory examples, not measurements from your recording.

English is the default and fallback language. All 24 user chapters have French translations with shared page and section IDs. Technical archives and exact API schemas retain their original language and are marked accordingly; [Translation status](doc:translation-report) lists outstanding translations instead of pretending they exist. Some dated references describe older behavior; current guides take precedence.
